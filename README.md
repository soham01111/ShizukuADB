# ShizukuADB Tool

ADB aur Fastboot commands ko Shizuku ke through run karne wali Android app.

## Features
- ADB Devices list
- Device Info (Model, Brand, Android Version)
- Battery Status
- Installed Apps list
- Screenshot lena
- Reboot (Normal, Recovery, Bootloader)
- Fastboot Commands
- Custom command input

## Requirements
- Android 8.0+
- Shizuku app installed aur running

## GitHub se APK kaise banaye

1. Is repository ko apne GitHub account mein **Fork** karein
2. Fork ke baad **Actions** tab mein jaayein
3. **"Build APK"** workflow pe click karein
4. **"Run workflow"** button dabayein
5. 5-10 minute wait karein
6. **Artifacts** section mein `ShizukuADB-APK` download karein
7. APK ko phone mein install karein

## Shizuku Setup
1. Play Store se Shizuku install karein
2. Developer Options mein Wireless Debugging ON karein
3. Shizuku app open karein aur Start karein
4. ShizukuADB app ko permission dein
